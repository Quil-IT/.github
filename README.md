# .github

Organization-wide defaults for Quil-IT.

- `profile/README.md`: the public profile shown on https://github.com/Quil-IT
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`: default policies for every repository that does not define its own
- `.github/ISSUE_TEMPLATE/` and `.github/pull_request_template.md`: default issue and pull request templates

A file placed in an individual repository overrides the default here.
