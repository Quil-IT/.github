# Security Policy

## Reporting a vulnerability

Please do not report security issues through public GitHub issues, discussions or pull requests.

Email **quilit.team@gmail.com** with the subject line `Security report`, and include:

- the affected repository, URL or product
- steps to reproduce, or a proof of concept
- the impact you believe it has

Where a repository has private vulnerability reporting enabled, you can also use the **Report a vulnerability** button on its Security tab.

We will acknowledge your report, keep you updated while we investigate, and credit you once a fix is released if you would like to be named.

## Scope

This policy covers all repositories owned by the Quil-IT organization. Please do not access, modify or delete data that is not yours, and do not run tests that degrade service for others.
